# Once Human Guide — working notes

## What this app is
FastAPI + SQLite game-companion API (`api_main.py`), served together with a
static v19 HTML shell. No Node/JS build step, no external services, no secrets.

## Non-obvious setup facts
- `api_main.py` needs `once_human.db` in the repo root. It is **gitignored** and
  is generated by `db_build.py` from `database_full.json` (or the per-table
  `*.json` modules). `start.sh` refuses to run without it.
- `api_main.py` serves the UI at `/ui`, data at `/stats`, `/search`, `/export`,
  and one list endpoint per table. `/health` returns 200 even when the DB is
  missing — use `/stats` to check DB readiness.

## CI (`.github/workflows/python-app.yml`)
Runs on pushes/PRs to `main` and has two failing points to keep green:
- `flake8 . --count --select=E9,F63,F7,F82` → must report **0** errors.
- `pytest` → must collect at least one test (`tests/`), otherwise pytest exits 5
  and the job fails.

Run locally:
```bash
python -m pip install -r requirements.txt flake8 pytest
flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics
pytest
```

## Sandbox / preview (`docker-compose.base44.yml`)
- `db` (one-shot) builds the SQLite DB, then `api` starts from the bind-mounted
  source with `uvicorn --reload`; public preview is host port **3000** → 8000.
- `WATCHFILES_FORCE_POLLING=true` makes reload work across the bind mount.
- Verify: `curl http://localhost:3000/health`, `curl http://localhost:3000/stats`.
