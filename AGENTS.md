# Base44 Dev Environment

## Overview
This is a **Once Human Guide** — a FastAPI app serving game data (weapons, armor, deviations, bosses, etc.) from a SQLite database assembled from JSON module files. No external credentials are required.

## Architecture
- **Backend**: FastAPI (`api_main.py`) on port 8000 (mapped to host port 3000)
- **Database**: SQLite (`once_human.db`), built on startup from 17 JSON module files via `base44_build.py` (which reuses `install.py`'s assembly logic)
- **UI**: Served at `/ui` — a minimal HTML page generated by `install.py`'s `write_minimal_ui` (the full `once_human_guide_ui_v4.html` is not in the repo; it's an optional GitHub download)
- **Live reload**: uvicorn `--reload` watches `/app` for changes

## Startup Flow
1. `pip install -r requirements.txt` (fastapi, uvicorn)
2. `python3 base44_build.py` — assembles `database_full.json` from JSON modules, builds `once_human.db`, writes minimal UI HTML
3. `uvicorn api_main:app --host 0.0.0.0 --port 8000 --reload`

## Key Endpoints
- `GET /` — API status + table list
- `GET /ui` — minimal HTML UI
- `GET /stats` — record counts per table
- `GET /search?q=<term>` — cross-table search
- `GET /export` — full data export
- `GET /{table}` — list records (deviations, weapons, armor, mods, bosses, locations, recipes, materials, scenarios, quests, events, creatures, npcs, plants, fish, animals, flowers)
- `GET /{table}/{id}` — single record

## Notes
- The `react-app/` and `expo-app/` directories are empty placeholders (not used).
- `install.py` and `updater.py` are the original installer/updater scripts for end-user deployment; `base44_build.py` is the dev-only DB builder.
- No external services or secrets are needed.
