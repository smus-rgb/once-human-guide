# Lonewolf Set

**LEGENDARY** · Juggernaut · 4 pieces

## Lore
Lonewolf is the endgame set for those who hunt alone. Critical hits become a growing shadow of power that overwhelms any anomaly.

## World / Set Bonuses (exact – never omit)

| Pieces | Bonus |
|--------|-------|
| **1**  | Magazine Capacity **+10 %** |
| **2**  | Crit Rate **+5 %** |

| **4**  | Max Lone Shadow stacks increased to **10** (+60 % Crit DMG). Crit Rate **+8 %** for 2 s after reloading. |
