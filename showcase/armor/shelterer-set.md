# Shelterer Set

**LEGENDARY** · Wanderer · 4 pieces · Elemental foundation

## Lore
Shelterer is the core armor for elemental survivors. Status and elemental power grow with every hit until the anomaly is overwhelmed.

## World / Set Bonuses (exact)

| Pieces | Bonus |
|--------|-------|
| **1**  | Status DMG Reduction **+15 %** |
| **2**  | Element DMG (Blaze / Frost / Shock / Blast) **+8 %** |
| **3**  | Each weapon hit grants 1 stack of **Deviant Energy**. Every stack = **+1 % Elemental DMG**. Max **20** stacks. Reloading removes half the stacks. |
| **4**  | Max Deviant Energy stacks **+10** (total 30). Weakspot hits grant **2** additional stacks. |

## Synergies
- Best with Blaze / Shock / Frost weapons (EBR-14, ACS12 Pyroclasm, AUG Electron Cloud, ACS12 Corrosion…)
- High magazine weapons keep stacks longer (avoid frequent reloads)
