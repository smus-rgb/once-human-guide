# SN700 – Finale

**LEGENDARY** · Sniper Rifle · Shrapnel · 3.0.1+

## Lore
SN700 – Finale is a precision Shrapnel sniper added with the 3.0.1 anniversary. Weakspot hits guarantee Shrapnel procs, making it a top single-target bossing tool.

## Key Features
- Hits chance to trigger Shrapnel
- Weakspot hits **guarantee** Shrapnel
- Blueprint system weapon

## Synergies

- Shrapnel Crit builds
